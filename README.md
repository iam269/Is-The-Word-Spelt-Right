# Is The Word Spelt Right? 🎯

A thrilling spelling challenge game! 🧠 Test your vocabulary and spelling skills by quickly deciding if displayed words are spelled correctly or incorrectly. Press **Correct ✅** or **Wrong ❌** and see if you're right! Keep your lives intact and watch your score soar! 🏆

- **Lives**: Start with 3 ❤️❤️❤️
- **Goal**: Achieve the highest score possible! 📈
- **Fun Factor**: Fast-paced and addictive! ⚡
